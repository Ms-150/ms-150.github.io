# geminicli

`Gemini CLI` 将 `Gemini` 车型的强大功能直接带入您的终端。用它来理解代码，自动化任务，并结合本地项目背景构建工作流程。

[https://geminicli.com/](https://geminicli.com/)

::: code-group

```bash [node]
npm install -g @google/gemini-cli
```

```bash [brew]
brew install gemini-cli
```

:::

## usage

::: code-group

```bash [version]
gemini -v
```

```bash [start]
gemini
```

```bash [init]
/init 
# 生成 .gemini/ 配置
```

```bash [plan]
/plan
```
:::
